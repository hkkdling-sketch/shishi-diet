部署识别代理约 5 分钟

把 API Key 放到一个免费的小服务里，识食就再也不用填 Key —— 所有设备永久免配置。

🌐 打开识食 📱 上手指南 GitHub 源码
先确认你需不需要做这个 只在一个手机上用 → 不用折腾，直接填一次 Key 就好，1 分钟搞定。

这个方案是给下面这些情况的：① 多台设备（手机 + 平板 + 电脑）； ② 经常清浏览器数据；③ 想分享给别人用，但不想把自己的 Key 给别人。
做完之后是什么效果 你只需要在识食里填一个网址，Key 那一栏留空。
之后换手机、重装浏览器、清理数据 —— 都不用再填任何东西。
1拿一个 API Key
  1. 打开 open.bigmodel.cn，注册 / 登录（手机号即可）
  2. 左侧找 「API 密钥」 或 「密钥管理」
  3. 点 「创建 API Key」，复制出来

复制出来大概是这个形状（32 位十六进制，中间可能有个点）：

a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6.Xy9Zk2Lm3Np4Qr5S

先存到记事本里 这串 Key 只在创建时显示一次，关掉页面就看不到了。丢了就再建一个。

免费模型是 GLM-4V-Flash，不用充值。

2创建 Cloudflare Worker
  1. 打开 dash.cloudflare.com，注册（邮箱即可，免费）
  2. 登录后，左侧菜单找 「Workers & Pages」（计算 / Compute 下面）
  3. 点 「Create」 → 选 「Create Worker」
  4. 名字随便起，比如 shishi-proxy → 点 「Deploy」
  5. 部署完会看到一个代码编辑器 → 点 「Edit code」

编辑器里默认有一段示例代码，全选删掉，下一步粘贴我们的。

4配置环境变量（关键一步）

回到 Worker 页面 → 顶部 「Settings」 → 左侧 「Variables and Secrets」 → 点 「Add」，加下面两个：

变量名值类型
API_KEY 第 1 步复制的 Key Secret（选这个才会加密存储）
ALLOW_ORIGIN https://hkkdling-sketch.github.io Text
ALLOW_ORIGIN 一定要设对 这是防止别人白嫖你 Key 的唯一屏障。格式要求：
✅ 正确：https://hkkdling-sketch.github.io
❌ 错误：hkkdling-sketch.github.io（少了 https://）
❌ 错误：https://hkkdling-sketch.github.io/shishi-diet/（不要带路径和末尾斜杠）

加完之后必须再点一次「Deploy」，变量才会生效。这一步最容易漏。

（还有个可选的 UPSTREAM，默认是智谱，不用管。 想换成豆包就填 https://ark.cn-beijing.volces.com/api/v3， 模型填 doubao-seed-2-1-lite-260915（豆包个人开发者有 50 万 tokens 免费额度， 中文场景比智谱强；模型下线了就在火山方舟控制台的「模型广场」换最新的 ID）。）

5在识食里填地址
  1. 复制你的 Worker 地址（在 Worker 页面顶部，形如 https://shishi-proxy.你的名字.workers.dev）
  2. 打开识食 → 「拍照」 页 → 展开 「识别接口设置」
  3. 服务商选 「自建代理（不用填 Key）」
  4. API 地址：粘贴刚才那个 Worker 地址
  5. 模型：填 glm-4v-flash
  6. API Key：留空
  7. 点 「保存设置」 → 再点 「测试连接」

看到绿色的 「连接正常」 就成了。以后任何设备只要填这一个地址。

免费额度够用吗 Cloudflare Workers 免费版 每天 10 万次请求。 识食一次识别 = 1 次请求，个人用一天最多几十次，远远用不完。 智谱的 GLM-4V-Flash 目前也是免费的，所以整条链路 0 成本。

出问题了看这里

测试连接报「来源不被允许」
ALLOW_ORIGIN 没设对。回第 4 步检查三件事：① 有没有 https://；② 有没有多写路径或末尾斜杠；③ 改完有没有再点一次 Deploy。
报「Worker 还没配置 API_KEY」
变量名必须完全等于 API_KEY（全大写、下划线），类型要选 Secret，改完要重新 Deploy。
报「模型不在白名单内」
模型名写错了。填 glm-4v-flash。想用别的模型，就在 Worker 里加一个 ALLOW_MODELS 变量，把模型名逗号分隔列进去。
报「Key 不对」
说明 Worker 通了，但智谱拒绝了 Key。检查第 1 步的 Key 有没有复制完整、有没有多余空格。也可以在智谱后台确认 Key 还有效。
识食里 API 地址到底要不要带 /chat/completions？
不要带。只写到 https://xxx.workers.dev 就行。识食会自己拼上 /chat/completions —— 带上反而会变成 .../chat/completions/chat/completions，然后 404。
担心别人拿我的地址刷
已经做了两层防护：来源校验（只有你的站点能调）和模型白名单（只能用便宜的模型）。想再加一层，可以在 Cloudflare 的 Security → WAF → Rate limiting rules 里加一条「同一 IP 每分钟最多 10 次」，免费额度内够用。
用了代理，我的照片会经过第三方吗？
会 —— 照片会经过你自己的 Worker 转发给模型厂商。Worker 只是转发，不落盘、不记录。

但如果你对隐私有要求，就继续用直连 + 自己填 Key —— 那样照片只在你和模型厂商之间传输，不多一跳。 这是取舍，不是「代理更好」。
以后想换成通义千问 / OpenAI
在 Worker 里加两个变量：UPSTREAM = 新厂商的地址（如 https://dashscope.aliyuncs.com/compatible-mode/v1）， API_KEY 换成新厂商的 Key，ALLOW_MODELS 加上新模型名。识食那边不用改。
