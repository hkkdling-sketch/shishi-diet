识别接口设置
没有 Key 也能用：不配接口时，用内置 109 条食物库 + 手动输入照样能记账。配了之后拍照自动填营养表，省事很多。
2026-10 实测：只有通义放行浏览器跨域，填 Key 直接能用；豆包和智谱的接口不放行跨域，必须经「自建代理」中转。豆包个人开发者有 50 万 tokens 免费额度、中文场景强（Key 在 console.volcengine.com → 火山方舟）；智谱视觉模型本身免费。Key 只存本机，不会上传。
支持 OpenAI 及任意兼容接口（智谱、通义千问等），必须选支持看图的模型。
不想每台设备都填一次 Key？
识食没有服务器，所以 Key 只能存在每台设备的浏览器里 —— 换设备就要重填。

解法：把 Key 放到一个免费的小代理上（Cloudflare Worker），识食只填代理地址、Key 留空。
部署一次，所有设备永久免配置。

代码和 5 分钟部署步骤在仓库的 proxy/ 目录里。
