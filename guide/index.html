一、装到桌面

先澄清一件事：识食没有「安装包」可以下载 它不是从应用商店下的那种 App，而是一个网页应用（PWA）。
所以：没有 APK 文件、应用商店里搜不到。
「下载」= 用浏览器打开，然后「添加到主屏幕」。加完之后桌面会多一个图标， 点开就是全屏 App，没有地址栏——这就是安装完成了。
最省事的办法：用应用里自带的按钮 打开识食后，首页顶部有一条 「装到桌面，断网也能记」 的横条。 安卓点它右边的按钮就会弹出系统的安装框，点一下确认就行，不用去翻浏览器菜单。

如果没看到那条横条，或者点的是「怎么装」，会弹出对应你手机的图文步骤。
也可以随时去 「我的」页 找到安装卡片。

手动装也不难，分两种手机：

iPhoneSafari
  1. 用 Safari 打开链接
  2. 点底部中间的 分享按钮（方框带向上箭头）
  3. 往下滑，选 「添加到主屏幕」
  4. 右上角 「添加」
⚠️ 必须是 Safari。微信内置浏览器、Chrome 都做不了这一步。
安卓Chrome / Edge
  1. 用 Chrome 或 Edge 打开链接
  2. 点右上角 ⋮ 菜单
  3. 选 「安装应用」（有的叫「添加到主屏幕」）
  4. 确认
⚠️ 国产浏览器菜单里叫「添加到桌面」，位置可能不同，不好找就换 Chrome。
为什么一定要装到桌面？ 不装的话，每次都要开浏览器、找书签、等加载。装了之后点一下图标就是全屏 App， 没有地址栏干扰，而且 Service Worker 能把页面缓存下来——断网也能记录。

二、第一次用：建档

打开后先切到 「我的」 标签，把这几项填了：

身高 / 体重
算基础代谢用，不填其他页面都算不出数字
年龄 / 性别
影响基础代谢和膳食纤维推荐量
活动系数
平时运动量，5 档。拿不准选「轻度活动」
目标
减脂 / 保持 / 增肌，5 档
蛋白质 g/kg
减脂建议 1.6–2.0，普通 1.2 就够

填完下方会立刻算出你的 BMR / TDEE / 今日目标，以及训练日和休息日两套对照。

为什么要有两套目标？ 今天练了和今天没练，身体该吃的东西不一样。识食会自动判断： 你今天有训练记录 = 训练日，否则 = 休息日。训练日热量目标更高、蛋白质更多、膳食纤维多 5g。 你不用手动切，它自己认。

三、第二次用：入库

这是识食和别的热量 App 最不一样的地方。切到 「库存」 标签，把冰箱里的东西按克重录进去。

比如：鸡胸肉 1000g、鸡蛋 500g、牛奶 1000ml、西兰花 300g……

录入方式三种，随便挑：

拍照识别
在「拍照」页拍包装上的营养成分表，识别后点 「只加入库存」
内置食物库
87 条常见食材，搜索选择即可
手动输入
食物库里没有的，自己填名称和营养
这一步值得花 5 分钟 录完之后，每次吃东西只要点一下「扣减」，它就知道你冰箱还剩多少、 还能吃几天、该买什么了。而且推荐吃什么也是从你真实有的东西里挑， 不会推一个你根本没有的食材。

四、每天就两件事

① 吃东西了 → 记一笔

  1. 打开「拍照」页
    或者直接从「库存」页点某个食材的「吃掉」
  2. 选图 + 填克重
    两个按钮：「拍照」直接开相机；「从相册选」用你手机里已经拍好的照片——不用为了识别重新拍一遍。相册可以一次选多张（最多 6 张），选完能逐张删掉不想要的。AI 识别完一定人工核对一下，可以改。
  3. 选一个按钮
    「记入今日·并扣减库存」——吃的是冰箱里的，库存跟着减
    「外食·不扣库存」——在外面吃的，只记营养，不动库存

② 练了 → 录一下

  1. 打开「训练」页 → 记录训练
    选「跑步」
  2. 填距离
    比如 5 km。用时填 30 分钟（选填）
  3. 看实时预估
    下方会立刻显示 −363 kcal，还会告诉你用的哪种算法
为什么填距离而不是配速？ 因为跑同样距离消耗的热量，跟你跑多快基本无关。 5 公里，25 分钟跑完和 40 分钟跑完，消耗几乎一样。 所以识食只问你「跑了多远」，不问配速——问配速反而会更不准。

如果戴了手表，可以顺便填一下平均心率，识食会切换成更准的心率算法， 还会告诉你处在哪个心率区间。

五、五个标签都干什么

今日
最核心的一页。「还差多少」实时显示热量 / 蛋白质 / 碳水 / 脂肪 / 膳食纤维各还差多少。 吃超了会显示 「超 X」 而不是清零。下面还会从你库存里推荐该补什么，一键去记录。
训练
记录训练 + 训练日历。日历上可以提前排好哪天练、练什么、多久； 排好的日程点一下就能带进记录，不用重填。
库存
你冰箱的数字版。消耗速度预测（每样食材还能吃几天）、自动采购清单、 每样食材的自定义提醒线、14 天消耗曲线。想推推广告也在这页。
拍照
拍照识别 + 外食手填。AI 接口设置也在这里。三个按钮分别对应： 扣库存 / 不扣库存 / 只加入库存。
我的
个人资料、训练日 / 休息日目标对照、休息日热量调整、自定义动作库、 体重趋势、数据导出导入。

六、AI 拍照识别（可选，但要配 Key）

不配也能用——内置 87 条食物库 + 手动输入完全够起步。配了之后拍张照就能自动填营养表，省事很多。

免费方案（国内直连，不用梯子）：

  1. 注册智谱账号
    open.bigmodel.cn → 创建一个 API Key
  2. 进识食的「拍照」页
    展开最下面的「识别接口设置」
  3. 选服务商
    选 「智谱 GLM-4V-Flash（免费）」
  4. 粘贴 Key → 保存
    之后就能拍照识别了
Key 存在哪？ 只存在你自己手机浏览器的 localStorage 里，不会上传到任何服务器，识食本身也没有服务器。 申请时额度用不完的话，GLM-4V-Flash 目前是免费的。

另外还有两个预设：通义千问 Qwen-VL、OpenAI GPT-4o-mini。任何 OpenAI 兼容的接口都能填自定义地址。

七、数据备份（这条很重要）

数据只在你手机本地，丢了自己找不回来 识食没有服务器、没有账号，「不上传」是它的优点，但代价是： 清理浏览器数据、换手机、卸载浏览器，记录就全没了。

所以养成习惯——每隔一两周去 「我的」页 → 导出备份，存一个 JSON 文件（发到自己微信文件传输助手就行）。

换手机时在新手机上 「导入备份」，数据就回来了。

为什么不做云同步？ 因为云同步意味着要有服务器、要有账号、要承担隐私责任。识食选择做成单文件、零后端， 数据永远不出你这台设备。代价就是需要你自己备份——这是个明确的取舍，不是遗漏。

八、常见问题

能不能用手机里已经拍好的照片？不想为了识别再拍一遍。
能。「拍照」页有两个按钮：「拍照」和「从相册选」。点「从相册选」就会打开你的相册，挑之前拍好的图就行。还能一次选多张——选错了点缩略图右上角的 × 删掉，或者点「清空」重来。
拍包装食品要拍两张（配料表 + 营养成分表），要分两次识别吗？
不用。一次把两张都选进来，一起发过去识别，模型会在同一个上下文里交叉比对，比分开识别两次更准。最多支持 6 张。
「今日限量」里的钠、饱和脂肪、糖是什么？我该盯着哪个？
这三项是国标 GB 28050 要求食品标签必须标的东西，因为「吃多了」比「吃少了」更常见。它们和上面的热量、蛋白质语义相反——上面那些要吃到，这三项要压住。钠最值得盯：中国饮食的钠普遍超标，而它是高血压的第一风险因素。上限是钠 2000mg、饱和脂肪和糖各不超过总热量的 10%。
「自适应消耗」是什么？要开吗？
它是用你自己的数据反推真实消耗，比公式估算准。原理是能量守恒：你吃了多少、体重怎么变，就能反推出你实际消耗了多少。

需要连续 14 天饮食记录 + 跨度 14 天以上的体重记录才会启用，不够时它会告诉你还差多少。

⚠️ 关键：别漏记整餐。只记两餐的话，它会以为你吃得少，从而把你的消耗也估低，目标越调越低。识食会自动剔除「明显漏记」的日子，但最好的办法还是尽量记全。
为什么拍照识别要我自己填 API Key？不能直接用吗？
因为识食是零后端的 —— 它没有服务器，所以没有地方能安全地存一个「公共 Key」。 把 Key 写进代码里，会被公开仓库的爬虫扫到并盗刷，几小时就能刷爆。

但你要做的事很少：去 bigmodel.cn 注册（1 分钟），建一个 API Key，粘进识食，点「测试连接」确认通了 —— 每台设备只做一次。而且 GLM-4V-Flash 目前免费，不花钱。

如果你有好几台设备、不想每次都填：仓库里带了一个现成的代理方案（proxy/ 目录）， 把 Key 放到免费的 Cloudflare Worker 上，识食只填地址、Key 留空，所有设备永久免配置。5 分钟能部署好。

完全不配也行。内置 109 条食物库 + 手动输入，记账功能一点不受影响。
点了「测试连接」报错，看不懂怎么办？
识食会把报错翻译成人话：
· 连不上 → 地址写错了，或这个接口不允许浏览器直连（CORS）
· Key 不对 → 没复制完整，或多了空格
· 地址或模型名不对 → API 地址只能写到 /v4 这一级，不要加 /chat/completions
· 请求太频繁 → 额度用完了，等一会儿或换一个 Key
应用商店里搜不到识食？有没有 APK 可以下载？
都没有，这是正常的。识食是网页应用（PWA），不做安装包、也不上架应用商店——因为上架要开发者账号、要服务器、要审核，而识食刻意做成零后端、零账号。「安装」的方式就是上面的「添加到主屏幕」。
首页那条「装到桌面」的横条怎么没了？
三种情况：① 你已经装了（在桌面图标里打开时不会显示）；② 之前点过右边的 ×；③ 安卓 Chrome 判断你已装过。想找回来就去 「我的」页，那里有常驻的安装卡片。
添加到主屏幕后图标是空白的 / 名字不对？
删掉重新添加一次。如果还是不行，说明浏览器没读到 manifest.json——确认你打开的是完整网址（带 /shishi-diet/ 结尾），不是某篇文章里的链接。
更新了版本，我手机上还是旧版？
Service Worker 会先给你缓存的旧版（这样打开才快），再后台悄悄下载新版。关闭 App 再打开一次就更新了。如果还没变，等一分钟再开。
拍照识别报错 / 一直转圈？
检查三件事：① Key 填对了吗（别多空格）；② 选的模型和 Key 是不是同一家的；③ 网络能不能通。想快速排除网络问题，可以先不填 Key，用内置食物库测试记录功能是否正常。
我吃了半个苹果，库存里没有苹果怎么办？
直接走 「外食·不扣库存」 或手动填一条就行。库存是给你家里存的东西用的，临时买的不必入库。
跑步消耗算出来和我手表不一样？
手表多半用了心率带 + 个人 VO2max 建模，更准。识食用的是体重 × 距离的通用公式，误差通常在 5–10%。想更准就填平均心率，会切换到心率算法。任何 App 的消耗都是估算，别当精确值用。
训练日 / 休息日怎么切换？要手动设吗？
不用。有训练记录就是训练日，没有就是休息日。你也可以在「训练 → 日历」里提前排课，排了就算训练日。
能在电脑上用吗？
能，同一个链接用浏览器打开就是完整功能，界面会自适应。但手机上用最方便——毕竟你要拍照。数据不会自动同步，是两套独立的本地数据。
要付费吗？有什么隐藏费用？
完全免费，MIT 开源，可以商用。唯一的成本是如果你要用 AI 拍照，那部分是你自己给模型厂商付（智谱 GLM-4V-Flash 目前免费）。识食本身不碰钱、也没有账号体系。
一句话总结每天怎么用 吃东西 → 拍照页记一笔；练了 → 训练页填距离；然后看今日页还差多少。 就这三件事。
